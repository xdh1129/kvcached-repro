兩張 GPU 同時換 model 時，資料搬移卡在哪裡

兩組實驗。Agent 輪流 workload：每張 GPU 跑 8 個 agent（4 種 3B–8B model 各 2 份），一共 24 輪，request 依 1_1, 2_1, …, 8_1, 1_2, … 的順序交錯送出，每個 request 都要用 LRU 換入 weights 和保留的對話 KV。Wake storm：兩張 GPU 同時 wake，每個 model 10.5 GiB weights 加 5.4 GiB KV。路徑寫成 weights+KV；GDS 路徑開 256 MiB staging；其餘都是 vLLM 預設設定。

    數據來源：results/agent_rr_g67_*、results/wake_storm_g67_kv5_d0_*；由 analysis/make_figures.py 產生，同一份數據也輸出成 results/figures/*.png。
